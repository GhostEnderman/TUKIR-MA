# Our 3 Years — Anniversary Website

1. Open `index.html` to preview the site on your PC.
2. The five uploaded photos are already included in `photos/`.
3. The site is designed mobile-first and works offline.
4. To add your own legally obtained audio file, add it to the project and modify the music button/audio section in `index.html`.
5. To get a shareable link, upload this folder to a static host such as GitHub Pages, Netlify, or Cloudflare Pages.

Note: the website does not include the copyrighted song itself.
